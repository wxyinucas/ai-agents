# 旧行情实验素材

本目录与旁边的 `common/` 来自旧 `ai-agents-project` 快照，迁移来源与使用边界见 [历史素材说明](../README.md)。它不承担当前周次的任务发布。

- [`week-03/`](week-03/)：本地 CSV 检查的任务、样例、公开测试与报告模板。
- [`week-04/`](week-04/)：在 CSV 检查上增加两处 trace 的任务与测试。
- [`references/`](references/)：上述两份任务的独立、可运行参考实现。
- [`pilots/longbridge-readonly-v1/`](pilots/longbridge-readonly-v1/)：旧数据合同与合成故障案例，静态保留。
- [`pilots/longbridge-gate-a/`](pilots/longbridge-gate-a/)：历史平台工具与脱敏试跑记录；只将隔离单测用于迁移核验。

当前学生材料在仓库根目录的 `week-XX/`；后续持续项目在 `project/`，不沿用这里的旧 `students/sXX/system/` 初始化流程。
