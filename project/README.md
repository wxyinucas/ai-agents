# 后续持续项目

本目录用于 W10～W15 逐步维护的同一份项目：从市场数据产生目标持仓，做历史验算，再接入模拟执行、核对反馈并修改后重跑。

- 每周任务、公开测试、合成样例和教师参考仍放在仓库的 `week-XX/`，以当周 Guide 指定的入口为准。
- 持续项目的源码、配置与自身测试在本目录演化，通过 Git 保留版本，不按周复制整份源码。
- 当前只登记目录职责；开始持续项目时，再按已确认的台本建立环境、程序入口与测试。不把 `legacy/` 的旧项目直接当作学生起始版本。

教师参考和学生个人实现的初始化方式随首次项目任务说明；不要求建立 `students/sXX/` 或切换另一个课程仓库。数据与输出的保存和公开范围继续遵守当周 Guide。
